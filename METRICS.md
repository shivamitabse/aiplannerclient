# Metrics

## North Star Metric

**Audit-to-Lead Conversion Rate (%)**

- **Why**: Since AI Spendly is a lead-generation tool for Credex, the ultimate measure of success is not just how many people run an audit, but how many of those audits result in a captured lead (email) or a booked consultation.

## Input Metrics

1.  **Viral Coefficient (k)**: The average number of new users generated by each shared public report URL. This drives the organic "viral loop."
2.  **Average Potential Savings Found ($)**: If this number is too low, the value proposition of the tool weakens. We aim for a "Hero Metric" of >$500/year found per average user.
3.  **Audit Completion Rate**: The percentage of users who start the form and reach the results page. This measures the UX friction of the input process.

## First Instrumentation

- `form_step_completed`: To identify which tool input causes the most drop-off.
- `report_shared`: Tracking which platform (Twitter vs. Slack) drives the most referral traffic.
- `credex_cta_clicked`: Measuring the "intent to buy" for high-savings cases.

## Pivot Decision

The number that would trigger a pivot decision is a **Lead Capture Rate < 2%**.

- If 98% of people see their results and leave without providing an email, it means the "value-to-friction" ratio is off. We would either need to move the email gate earlier (riskier) or add a more compelling "Bonus" (like the PDF export or Benchmarking) to justify the lead capture.
